リボルバー決闘 ― GitHub Pages への置き方
==========================================

■ 中身（どれも25MB以下なので、ブラウザからそのままアップロードできます）
  index.html   … ゲーム本体（プログラム入り）
  assets/      … キャラクター3体・リボルバー・モーション・サムネイル

■ アップロードのしかた
  1. GitHubで新しいリポジトリを作る（Public）
  2. リポジトリのページで「Add file」→「Upload files」
  3. このzipを解凍してできた「index.html」と「assets」フォルダを、
     そのまま画面にドラッグ＆ドロップ（フォルダごとでOK）
  4. 「Commit changes」を押す
  5. Settings → Pages → Branch を「main」「/(root)」にして Save
  6. 数分待つと表示されるURLを開けば遊べます

  ※ assets フォルダの中身は、必ず assets フォルダの中に入った状態で置いてください
  ※ index.html をパソコンで直接ダブルクリックしても動きません（サーバーに置いて開く必要があります）

■ 二人で遊ぶ
  ・Aさん：「部屋をつくる」→ 4けたの番号が出る
  ・Bさん：その番号を入れて「入る」
  ・会社や学校のネットワークでつながらないときは、スマホのモバイル回線で試してください
